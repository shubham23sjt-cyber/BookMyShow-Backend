## 1. User Roles & Access Control

The BookMyShow backend employs **Role-Based Access Control (RBAC)** to secure its endpoints. The database classifies users into two major roles under the `Role` enum:

| Role | Description | Endpoint Permissions |
| :--- | :--- | :--- |
| **`ADMIN`** | System operators managing inventory & analytics. | Has full read-write access to events, venues, shows, seat generation, and revenue/occupancy analytics. |
| **`USER`** | Public customers booking tickets. | Can view events, shows, check seat maps, hold seats, checkout bookings, and cancel their own tickets. |

### Access Control Mechanism
1.  **`JwtAuthGuard`**: Authenticates requests by extracting the Bearer Token, verifying it against the cryptographic key (`secretkey`), and attaching the user object (`userId`, `role`) to the request context.
2.  **`RolesGuard`**: Checks the authenticated user's role against the required roles metadata (assigned via the `@Roles` decorator) on the route handler.

## 2. Module Responsibilities

The application's architecture is segmented into dedicated modules, each holding clear business responsibilities:

```
┌────────────────────────────────────────────────────────┐
│                      NestJS App                        │
└──────────────────┬──────────────────┬──────────────────┘
                   │                  │
         ┌─────────▼────────┐        ┌▼─────────────────┐
         │   Admin Module   │        │  Booking Module  │
         └──────────────────┘        └──────────────────┘
                   │                  │
         ┌─────────▼────────┐        ┌▼─────────────────┐
         │   Seats Module   │        │   Auth Module    │
         └──────────────────┘        └──────────────────┘
```

### A. Authentication Module (`src/auth`)
*   **Registration**: Creates new users, hashing passwords via `bcrypt` (10 salt rounds) before database persistence.
*   **Authentication**: Validates user credentials and issues a stateless JSON Web Token (JWT) expiring in 24 hours.

### B. Seats Module (`src/seats`)
*   **Seat Generation (Admin)**: Generates seats for a given show according to customized pricing and count configurations.
    *   *VIP Seats*: Prefixed with `V` (e.g., `V1`, `V2`).
    *   *Premium Seats*: Prefixed with `P` (e.g., `P1`, `P2`).
    *   *Standard Seats*: Prefixed with `S` (e.g., `S1`, `S2`).
*   **Seat Map Lookup (Public/User)**: Fetches the seating chart for a show. It dynamically determines whether seats are:
    *   `isBooked`: Confirmed booked in the database.
    *   `isHeld`: Reserved temporarily by another user.
    *   `heldByMe`: Reserved temporarily by the current querying user.
*   **Seat Holds**: Locks selected seat IDs for the calling user for a duration of **10 minutes** to secure them during payment/checkout. Automatically cleans up expired holds prior to listing or updating seats.

### C. Booking Module (`src/booking`)
*   **Transactional Ticket Booking**: Processes checkouts securely inside a database `$transaction` to maintain ACID compliance:
    1.  Validates that all requested seats exist and belong to the correct show.
    2.  Verifies seats are not already booked or currently held by another user.
    3.  Calculates total pricing.
    4.  Creates a new booking record (marked `CONFIRMED`).
    5.  Associates seats with the booking.
    6.  Releases the temporary seat holds.
*   **Cancellations**: Cancels active bookings, removing seat-booking associations so they can be selected again by other users.

### D. Inventory Modules (`src/event`, `src/venue`, `src/show`)
*   **Event**: Manages content catalogs (e.g., Movie titles, duration, event type).
*   **Venue**: Registers physical properties (cinemas, halls) including locations and addresses.
*   **Show**: Schedules specific dates and times when an Event will run at a Venue. Prevents double-scheduling at the same venue and time.

### E. Admin & Analytics Module (`src/admin`)
*   **Revenue Analytics**: Sums up the prices of all `CONFIRMED` bookings grouped by Event.
*   **Occupancy Analytics**: Computes show-by-show seat capacity and percentage occupancy rates.
